# SDD &mdash; Spec-Driven Development

Talk de 20 minutes, en français. Le deck est `demoit.md`, la syntaxe Markdown
du moteur est décrite dans le `CLAUDE.md` à la racine du dépôt.

## Lancer le talk

Build du moteur depuis la racine du dépôt, puis :

```shell
demoit sdd-talk
```

Avec le live reload pendant l'écriture des slides (la page se recharge à chaque
sauvegarde de `demoit.md`) :

```shell
demoit --dev sdd-talk
```

Les slides sont servies sur http://localhost:8888. La fenêtre de notes est sur
http://localhost:8888/speakernotes, la vue d'ensemble sur `/grid`.

## Prérequis de démo

Rien pour l'instant : le deck ne contient pas encore de slide de démo. Cette
section listera ce qu'il faut avoir lancé avant de monter sur scène (services,
